Color Mixer Studio

A Krita plugin for mixing colors, creating palettes, and checking color contrast.

Color mixing

Set the Start Color and End Color using the color wheel, HEX/RGB input, or screen picker. The HSL value is displayed alongside the input fields. Choose the OKLCH, LAB, or RGB color space, the number of intermediate steps, and the HEX/RGB/HSL label format. The brush button applies a color as Krita's foreground color.

Palettes

Create a palette using the Complementary, Triadic, Analogous, Split-Complementary, or Monochromatic harmony. For images, choose Start Color, End Color, Extract Palette, or Custom Palette (Manual). Load an image from disk or capture a screen area with Snip Screen.

In Extract Palette mode, set the number of colors, sort by frequency, hue, or brightness, and choose a threshold for merging similar colors. The threshold uses CIE76 Delta E: 0 keeps only exact matches, while higher values merge increasingly similar colors.

In Custom Palette (Manual) mode, set 2 to 16 slots, select a slot, then click the desired color in the image. Fill all slots before exporting.

Contrast

In Color difference and contrast, choose a text color and a background color. The preview shows the selected pair, CIE76 shows the numerical difference between the colors, and Contrast shows the contrast ratio with an evaluation against WCAG text thresholds. This can help assess readability but is not a substitute for a full accessibility review.

Export

  • Add Palette as Layer (64x64) adds the palette as a horizontal strip on a new raster layer in the active document. Each color is a 64×64-pixel block with no gaps.
  • Save Palette as PNG saves the same color strip as a PNG.

An open Krita document is required to add a layer.
